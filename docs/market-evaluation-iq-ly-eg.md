# تقييم أسواق التوسع M9 — العراق / مصر / ليبيا

> وثيقة التقييم المطلوبة في `tasks.md` M9 + PRD §9 Phase 3. العراق هو سوق التجريب الأول (Pilot)؛ مصر وليبيا تقييم وثائقي فقط في M9، التنفيذ الكودي لهما مؤجل لـ M10+.

## 1. الخلاصة التنفيذية

| السوق | الأولوية M9 | القرار الكودي | الدفع | ملاحظة |
|---|---|---|---|---|
| **العراق (IQD)** | P0 — Pilot | **يُنفذ** (`IQD`, `IQ`, `ع.د`, Peg 1310 مع تجاوز يدوي) | Manual فقط (Stripe غير متاح) | سوق حيوي، تداول نقدي كبير، نفس شريحة LB/SY |
| **مصر (EGP)** | P1 — تقييم فقط | مؤجل M10 — `EGP`, `EG` جاهز تصميماً | Stripe متاح → `dual` لاحقاً | دراسة ضريبية/فوترة أعمق مطلوبة |
| **ليبيا (LYD)** | P2 — تقييم فقط | مؤجل M10 — `LYD`, `LY` | Manual فقط | سوق صغير، مخاطر تشغيلية أعلى |

## 2. العراق (IQD) — تفصيل Pilot

### 2.1 العملة والتنسيق
- **الرمز**: `IQD` — العرض `ع.د` (`LOCAL_CURRENCY_LABEL['IQD']='ع.د'`).
- **الـ ISO**: 368، `Intl.NumberFormat('ar-IQ', {style:'currency', currency:'IQD'})` مدعوم في Chromium/Firefox/WebKit الحديثة — اختبر `formatMoney(100_00,'IQD','ar-IQ')` يحتوي `ع.د`.
- **الكسور**: وحدتان عشريتان في الخزن (سنت)، العرض يبقى `2`؛ المصرف المركزي يعرض غالباً بدون كسور لكن الخزن بالسنت يحافظ على `money.ts` الموحد.
- **Peg الرسمي**: **1310 IQD / USD** (البنك المركزي العراقي، 2023–2026). السوق الموازي 1450–1600 متقلب — لذا الحل: **افتراضي 1310 + تجاوز يدوي** (`useExchangeRate`).

### 2.2 سعر الصرف في التطبيق
- LB/SY: يدوي يومي إلزامي (`QuickSidePurchase.vue:64-71` preview يمنع الحفظ بلا `rate`).
- IQ: `getDefaultRateForCountry('IQ') → 1310` إذا لم يجد `getRateForDate`. المستخدم يرى بانر `ocr.pegHint` — "السعر الرسمي 1310 — عدّله إن تعاملت بسعر السوق".
- `localToUsdCents(localCents, 1310)` — مثال: `131_000` سنت IQD (1310 IQD) = `100` سنت USD. `dayTotalUsdCents` نفسه.

### 2.3 الأونبوردنغ
- `COUNTRIES = ['LB','SY','IQ']`، علم `🇮🇶`، مفتاح `onboarding.iraq` في `ar.json`.
- `LOCAL_CURRENCY_BY_COUNTRY['IQ']='IQD'`.

### 2.4 الدفع
- Stripe **غير متاح** في العراق (قائمة Stripe المدعومة 2026 لا تشمل IQ). لذا `VITE_PAYMENT_MODE=manual` افتراضي لسوق IQ؛ `RenewalView.vue:95` يخفي Stripe ويظهر Whish/OMT المسار اليدوي نفسه (يُعاد استخدام نص Whish مع رقم عراقي لاحقاً — حالياً نفس الأرقام).
- لا تغيير لـ LB/SY (`dual`).

### 2.5 OCR
- نفس pipeline Google Vision لكل الأسواق — لا تخصيص لغوي IQ. النص العربي على الإيصالات العراقية يُقرأ بـ `TEXT_DETECTION` بدقة >85% بعد المراجعة اليدوية (الهدف M9).

### 2.6 التجريب
- 3–5 تجار عراقيين (بغداد/أربيل)، أسبوعان، مقاييس PRD §10 + دقة OCR.

## 3. مصر (EGP) — تقييم مؤجل

- **الرمز**: `EGP` — `ج.م`، `ar-EG`، سعر صرف عائم ~51 EGP/USD (2026) — لا Peg، يدوي إلزامي.
- **الدفع**: Stripe **متاح** في مصر (دعم 2024) → عند التنفيذ: `dual` (Stripe + فوري/تحويل بنكي محلي كبديل manual).
- **الضرائب**: فوترة إلكترونية إلزامية (ETA) — تتطلب دراسة قبل pilot.
- **التعريب**: `ar-EG` يختلف طفيفاً عن `ar-LB` لكن `ar.json` واحد يكفي لـ M9؛ تخصيص لاحق إن لزم.

## 4. ليبيا (LYD) — تقييم مؤجل

- **الرمز**: `LYD` — `د.ل`، `ar-LY`، سعر ~4.8 LYD/USD (مصرف ليبيا المركزي) مع سوق موازي.
- **الدفع**: Stripe غير متاح — Manual فقط.
- **المخاطر**: سوق أصغر، بنية إنترنت أضعف، مخاطر تشغيلية — pilot أخير.

## 5. قرارات معمارية عامة

- **عملة واحدة محلية لكل تاجر** (كما اليوم) — لا تعدد عملات في نفس الحساب. IQ تاجر يرى IQD+USD فقط.
- **`CurrencyCode` الموسع**: `'USD'|'LBP'|'SYP'|'IQD'|'LYD'|'EGP'` لكن M9 يفعّل `IQD` فقط كـ `LocalCurrencyCode`.
- **لا تغيير مخطط Supabase** — `profiles.local_currency` نص حر، يقبل `IQD` بلا migration.
- **Flag**: `VITE_ENABLED_COUNTRIES=LB,SY,IQ` (أو `src/config/countries.ts` لاحقاً) للتحكم بلا rebuild إن استُخدم `profiles.country` whitelist.
